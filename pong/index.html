Pong in Construct 3

Draw the sprites in Piskel, build the game in Construct 3, and play it on your phone.

What you will build

A one-player Pong game: you control the left paddle and the computer controls the right one. The ball bounces off the walls and paddles, speeds up a little with every hit, and the score goes up when someone misses.

ToolWhat it is forLink
PiskelDrawing the paddle and ball spritespiskelapp.com
Construct 3Building the gameeditor.construct.net
  • Both tools run in the browser. Nothing needs installing.
  • The finished game uses 7 events and 1 layer. The free version of Construct 3 allows 50 events when you are logged in, so there is plenty of room.
  • Time: about two class periods. Parts 1 to 4 in the first, Parts 5 to 7 in the second.
  • Click a part to open it. Opening one part closes the others. Tick every checkpoint box before you move on; your ticks are remembered on this computer.

Lesson brief

If you already know Construct 3, follow the chart and you can finish from it alone. Click any box to jump to its full steps; the Back to the brief button brings you back here.

Part 1 · Draw the sprites in Piskel

You need two images: a white paddle and a white ball. The walls will reuse the paddle image, so there is no third drawing.

1A · Paddle

PanelFieldValue
ResizeWidth8
Height32
Maintain aspect ratioOff
SaveTitlepaddle

All other settings stay at their defaults.

  1. Go to piskelapp.com and click Create Sprite. A blank 32 × 32 grid appears.
  2. On the right side, click the Resize button (the square with arrows). Untick Maintain aspect ratio, type 8 for Width and 32 for Height, then click Resize. The grid turns into a tall, thin strip.
  3. On the left, click the top colour square and choose white (#ffffff).
  4. Pick the Paint bucket tool and click inside the grid. The whole strip turns white.
  5. Click the Save button on the right and type paddle in the Title box. The name at the top of the screen changes to paddle.
  6. Click the Export button on the right, open the PNG tab, and click Download. A file called paddle.png appears in your Downloads folder. If it is called New Piskel.png, rename it paddle.png.

1B · Ball

PanelFieldValue
ResizeWidth8
Height8
SaveTitleball
  1. Reload piskelapp.com and click Create Sprite again.
  2. Click Resize, type 8 and 8, and click Resize. The grid becomes a small square.
  3. Choose white and fill the square with the Paint bucket.
  4. Optional: pick the Eraser and click each of the four corner pixels. The square now looks rounder.
  5. Set the Title to ball in the Save panel.
  6. Export → PNG → Download. Check that ball.png is in your Downloads folder.

Part 2 · Start the Construct 3 project

The game area is 1280 × 720, landscape, with a black background.

2A · New project

New projectValue
NamePong
Viewport size1280 × 720
  1. Go to editor.construct.net. If you have an account, log in first. Logged in, the free version allows 50 events.
  2. Click New project.
  3. Type Pong in Name, and 1280 and 720 in Viewport size. Click Create.
  4. An empty layout opens with a dotted rectangle on it. The dotted rectangle is what the player will see.
Already working as a Guest and want to log in? Save first with Menu → Project → Save as → Download a copy, log in, then open the file again with Menu → Project → Open. Nothing is lost.

2B · Layout size

Layout propertiesXY
Size1280720
  1. In the Project Bar on the right, click Layout 1 under Layouts.
  2. In the Properties Bar on the left, set Size to 1280 and 720. The edge of the layout now lines up with the dotted rectangle.
Looks small? The editor shows the layout zoomed out to fit (the zoom percentage is at the bottom of the layout view). Hold Ctrl and scroll to zoom. This only changes the view, not the game.

2C · Black background

Layer propertiesValue
Initially visibleOn (leave it)
TransparentOff

  2. In the Properties Bar, untick Transparent if it is ticked (leave Initially visible ticked, or the whole layer disappears), then click Background color and choose black. The layout turns black.

3A · Left paddle

  1. On the Layout 1 tab, double-click anywhere inside the black area (or right-click it and choose Insert new object). The Create new object window opens.
  2. Click Sprite, type PaddleLeft in Name, and click Insert.
  3. Click on the layout. The Animations Editor opens.
  4. In the editor's toolbar, click Load an image from a file (the folder icon) and choose paddle.png. The bottom bar shows Size: 8x32 and the frame at the bottom shows the white strip. It is hard to see in the middle because it is white on a light checkerboard.
  5. Close the Animations Editor with the X in its top-right corner. The small paddle is now on the layout.
  6. In the Properties Bar, type the Position and Size from the table. The paddle jumps to the left side and gets taller.

3B · Right paddle

  1. Repeat 3A with the name PaddleRight and paddle.png.
  2. Type its Position and Size. It sits on the right side.
Pick the right one: make PaddleRight a new Sprite, not a copy of PaddleLeft. A copy is the same object, and in Part 5 the two paddles need different events.

3C · Ball

  1. Insert a new Sprite called Ball and load ball.png.
  2. Type its Position, Size and Angle from the table. The ball sits in the centre. Its angle is the direction it will fly at the start.

3D · Walls

  1. Insert a new Sprite called Wall and load paddle.png.
  2. Type the top wall's Position and Size. A thin white line runs across the top.
  3. In the Project Bar, find Wall under Object types and drag it onto the layout. A second wall appears.
  4. Type the bottom wall's Position and Size. Now there is a line across the bottom too.
Pick the right one: both walls must be the same object type. In the Project Bar there should be only one Wall. This way one behaviour in Part 4 covers both.

Part 4 · Make things move

Behaviours are ready-made movement. You add one to an object, set a few values, and press Preview to watch it work.

How to add a behaviour (used in every step below): click the object on the layout, find Behaviors in the Properties Bar, and click the Behaviors link. In the window that opens, click Add new behavior, pick the behaviour, and click Add. Close the window. The behaviour's settings now show in the Properties Bar.

4A · Ball: Bullet

BulletValue
Speed400
Acceleration0
Gravity0
Bounce off solidsOn
Set angleOff
  1. Add the Bullet behaviour to Ball (it is under Movements).
  2. Type the values from the table.
  3. Click Preview (the play button at the top). (Shortcut: F5)
  4. The ball flies down and to the right, straight through the bottom wall and off the screen. Nothing stops it yet. Close the preview tab.

4B · Walls: Solid

  1. Click either wall and add the Solid behaviour (it is under Attributes). Both walls get it, because they are the same object.
  2. Preview again. The ball now bounces off the top and bottom walls. It still goes straight through the paddles. That gets fixed in Part 6.
Pick the right one: do not give the paddles Solid. In Part 6 an event makes the ball bounce off them and speed up at the same time.

Part 5 · The computer paddle

The right paddle chases the ball, but its top speed is lower than the ball's, so it can be beaten.

5A · Right paddle: 8 Direction

8 DirectionValue
Max speed250
Acceleration2000
Deceleration2000
DirectionsUp & down
Set angleOff
Default controlsOff
  1. Add 8 Direction to PaddleRight and type the values from the table.
What changed: nothing moves yet in Preview. Check that 8 Direction is listed under PaddleRight → Behaviors in the Properties Bar. Default controls is off so the arrow keys don't move this paddle. The events in 5B do.

5B · Events: follow the ball

EventCondition (left side)Action (right side)
1PaddleRight → Compare Y → Greater than → Ball.Y + 10PaddleRight → 8 Direction → Simulate control → Up
2PaddleRight → Compare Y → Less than → Ball.Y - 10PaddleRight → 8 Direction → Simulate control → Down

In words: if the paddle is below the ball, move up. If it is above the ball, move down. The 10 gives it a small dead zone so it doesn't shake.

Each event is one row with two halves: the condition on the left says when, and the action on the right says what happens.

  1. Click the Event sheet 1 tab at the top.
  2. Click Add event. Double-click PaddleRight, then double-click Compare Y.
  3. Set Comparison to Greater than, type Ball.Y + 10 in Y co-ordinate, and click Done. The condition appears on the left of the event.
  4. On the same event row, find the faint grey Add action text in the middle of the row. It looks greyed out, but it works. (Not Add event underneath.) Click it. Double-click PaddleRight; the window title should say Add 'PaddleRight' action. Double-click Simulate control in the 8Direction group. Choose Up and click Done. The action appears on the right.
  5. Add event 2 as a new row: click Add event at the bottom of the sheet, below event 1. (Not the grey Add action under event 1's action, which would add a second action to event 1, and not Add....) Then do it the same way, with Less than, Ball.Y - 10 and Down.
  6. Preview. The right paddle now follows the ball up and down.
Events remaining box: after your first event, a blue box may appear saying how many events you have left. It has no close button. Do not click Purchase a plan. Click the Add event link on the event sheet and the box goes away. You can keep working as normal.
Show screenshot
Pick the right one: if the window title says Add 'PaddleRight' condition, you are in the conditions list. Simulate control is an action: click Cancel and use the grey Add action instead. Use Simulate control from the 8Direction group, not Set Y, which teleports the paddle so it can't be beaten. In the Y field, type Ball.Y with a capital B and a dot.

Part 6 · Bouncing, speed-up and scoring

The ball bounces off each paddle and gets a little faster every hit. When it leaves the screen, the other side scores and the ball is served again from the centre.

6A · Global variables

Global variableTypeInitial value
ScoreLeftNumber0
ScoreRightNumber0
  1. Right-click an empty part of the event sheet and choose Add global variable.
  2. Type ScoreLeft, keep Type on Number and Initial value on 0, and click OK. A line Global number ScoreLeft = 0 appears at the top of the sheet.
  3. Add ScoreRight the same way.

6B · Bounce and speed up

EventConditionActions
3Ball → On collision with another object → PaddleLeftBall → Bullet → Bounce off object → PaddleLeft
Ball → Bullet → Set speed → Ball.Bullet.Speed + 25
4Ball → On collision with another object → PaddleRightBall → Bullet → Bounce off object → PaddleRight
Ball → Bullet → Set speed → Ball.Bullet.Speed + 25
  1. Add event → Ball → On collision with another object. Pick PaddleLeft and click Done.
  2. Add action → Ball → Bounce off object (Bullet group) → PaddleLeft → Done.
  3. Add action again → Ball → Set speed (Bullet group). Type Ball.Bullet.Speed + 25 and click Done. The event now has two actions.
  4. Make event 4 the same way with PaddleRight.
  5. Preview. The ball bounces off both paddles, and each rally gets faster.

Check your event sheet. Events 3 and 4 both start with Ball on the left.

Show screenshot
Pick the right one: there are two Set speed actions. Use the one in the Bullet group. Bounce off object is also in the Bullet group, under Ball, not under the paddles. Both collision conditions must start with Ball. "PaddleRight → On collision with PaddleRight" never happens, so the ball goes straight through.
Test tip: the ball starts out heading right. To check the left paddle first, set the ball's Angle to 160° on the Layout 1 tab, preview, then set it back to 20°.

6C · Scoring and serving

EventConditionActions
5Ball → Compare X → Less than → 0System → Add to → ScoreRight, 1
TextRight → Set text → ScoreRight
Ball → Set position → 640, 360
Ball → Bullet → Set speed → 400
Ball → Bullet → Set angle of motion → 20
6Ball → Compare X → Greater than → 1280System → Add to → ScoreLeft, 1
TextLeft → Set text → ScoreLeft
Ball → Set position → 640, 360
Ball → Bullet → Set speed → 400
Ball → Bullet → Set angle of motion → 160

In words: if the ball goes off the left edge, the computer scores. If it goes off the right edge, you score. Either way the ball goes back to the centre at its starting speed.

  1. Add event → Ball → Compare X. Choose Less than, type 0, click Done.
  2. Add the five actions in the order shown, using the grey Add action each time.
  3. Make event 6 the same way with Greater than, 1280, ScoreLeft, TextLeft and angle 160.
  4. Preview. Miss the ball on purpose: the right score goes to 1 and the ball serves again. Then get one past the computer: the left score goes to 1.
Pick the right one: Set angle of motion (Bullet group) changes the direction the ball travels. The plain Set angle rotates the picture and the ball keeps going the same way.

Part 7 · Play it on a phone

One more event lets a finger drag the left paddle. Then Remote Preview opens the game on a phone.

7A · Touch object

TouchValue
Use mouse inputOn
  1. Go back to the Layout 1 tab. Double-click the layout, choose Touch, and click Insert.
  2. Click Touch under Object types in the Project Bar and turn Use mouse input on.
What changed: nothing appears on the layout, because Touch is not a picture. Check that Touch is now listed under Object types. Use mouse input lets you test touch with the mouse on the school computer.

7B · Event: drag the paddle

EventConditionAction
7Touch → Is in touchPaddleLeft → Set Y → clamp(Touch.Y, 64, 656)

In words: while a finger is on the screen, the paddle moves to the finger's height. clamp keeps it between the walls (48 for half the paddle + 16 for the wall).

  1. On Event sheet 1, Add event → Touch → Is in touch → Done.
  2. Grey Add action → PaddleLeft → Set Y. Type clamp(Touch.Y, 64, 656) and click Done.
  3. Preview. Hold the left mouse button and move the mouse up and down. The paddle follows it and stops at the walls. The arrow keys still work too.
Pick the right one: use Is in touch, not On touch start. On touch start happens once, so the paddle would jump one time and then stop following.

7C · Remote Preview on a phone

  1. Click the small arrow beside the Preview button and choose Remote preview. A window shows a link and a QR code.
  2. Scan the QR code with your phone's camera and open the link. The game opens in the phone's browser.
  3. Turn the phone sideways and drag the left paddle with your finger.
  4. The game stays on the phone only while Remote Preview is open on the computer. Close it when you are done.
