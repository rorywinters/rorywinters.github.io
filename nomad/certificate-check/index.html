Check a Nomad Simulator certificate

For teachers. Type the student's name and the code exactly as they are on the certificate.

Spaces, capitals and punctuation in the name don't matter (Jo Smith and jo smith both match). A code only matches the name it was made for, so it can't be copied to another student. It stops casual copying, but it isn't cheat-proof. The score is part of the code (the two digits after the date), so it can't be changed: 10 means no hints, and each hint the student used takes off 1 point.
